# Translation

Write every text in one language, wrapped in `__()`. A translation file per language supplies the others.

```php
echo __('Hello, world!');
```

## Translation files

A file in `i18n/` named after the language returns `text => translation`.

```php
// application/i18n/es.php
return [
	'Hello, world!'      => '¡Hola, mundo!',
	'Welcome back, :user' => 'Bienvenido, :user',
];
```

```php
// application/i18n/es/mx.php: only what differs in Mexico
return [
	'Hello, world!' => '¡Qué onda, mundo!',
];
```

For the language `es-mx`, both files are read; the more specific one wins. A text without a translation is shown as written.

## Choosing the language

```php
// application/bootstrap.php: the language of the site
I18n::lang('es-mx');

// The current language
$lang = I18n::lang();
```

Per visitor, for example from the address:

```php
Route::set('localized', '<lang>(/<controller>(/<action>))', ['lang' => 'en|es|pt'])
	->filter(function (Route $route, array $params, Request $request) {
		I18n::lang($params['lang']);

		return $params;
	})
	->defaults(['controller' => 'Welcome', 'action' => 'index']);
```

## Values inside a text

Do not glue texts together: word order differs between languages. Use placeholders.

```php
echo __('Welcome back, :user', [':user' => HTML::chars($username)]);

echo __(':count articles by :author', [':count' => 12, ':author' => 'Ana']);
```

## Translating a text into a given language

```php
// Whatever the current language is
$subject = I18n::get('Your order', 'pt');

// Is there a translation? For finding texts that still need one
if ( ! I18n::has('Your order', 'pt'))
{
	Kohana::$log->add(Log::NOTICE, 'No Portuguese text for "Your order"');
}
```

## What the framework translates

- Validation error messages: see [Messages](messages).
- Month names from `Date::months()`.
- Texts of the error pages.

The system has starter files in `system/i18n/` (`es.php`, `fr.php`). Yours in `application/i18n/` are merged over them.

## Advice

- Write the text in `__()` as a full sentence, the way it is shown: it is also what translators see.
- `__()` only looks texts up. Formatting dates and numbers for a language is the job of `Date` and `Num`: see [Dates and Numbers](../helpers/dates).
