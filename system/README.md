# Kohana 4: the core

The core of [Kohana 4](https://github.com/uBizzy/kohana4): requests and responses, routing, controllers, views, validation, sessions, cookies, security helpers, logging, the profiler and the helpers.

- `classes/Kohana/` holds the classes; `classes/` holds the empty classes that extend them, so that an application can put its own in between.
- `config/`, `i18n/`, `messages/` and `views/` hold the defaults, which an application replaces file by file or key by key.
- `guide/kohana/` is the documentation, `tests/` the tests.

Start with the [README](../README.md) of the project.
