# Userguide module

Shows the guide of the framework, of every enabled module and of your application in your own site, with search and an API browser made from the code. Off in production.

Part of [Kohana 4](https://github.com/uBizzy/kohana4).

```php
// application/bootstrap.php
Kohana::modules([
	'userguide' => MODPATH.'userguide',
]);
```

The full documentation is in `guide/userguide/` and in the user guide of your application.
