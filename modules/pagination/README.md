# Pagination module

Splits a long list over several pages and prints the links to them.

Part of [Kohana 4](https://github.com/uBizzy/kohana4).

```php
// application/bootstrap.php
Kohana::modules([
	'pagination' => MODPATH.'pagination',
]);
```

The full documentation is in `guide/pagination/` and in the user guide of your application.
