# Security

## Reporting a problem

Open an issue in the repository: <https://github.com/uBizzy/kohana4/issues>

Say which version you use, what happens and how to see it happen. Issues
are public: describe the problem, and leave out anything that would help
somebody attack a site that is running today (a working exploit, the
address of an affected site).

This is a personal project: there is no promise of an answer within a
set time, but security problems are looked at first.

## Which versions get fixes

The latest version only. Kohana 4 moves with PHP in small steps, so the
fix for a problem is in the next version.
